# Обработка естественного языка
## Анализ тональности отзывов на Python

Программа анализирует текстовые отзывы о продукте и автоматически
классифицирует каждое слово на положительное, отрицательное или
нейтральное, а затем определяет общую оценку отзыва.

## Возможности

- Очистка текста от пунктуации и приведение к нижнему регистру
- Обработка устойчивых словосочетаний («проблем нет», «не работает»)
- Классификация слов по трём категориям на основе словарей
- Определение общей тональности: положительная / отрицательная / нейтральная
- Работа в диалоговом режиме до команды «выход»

## Как запустить

1. Установите Python 3.
2. Скачайте файл `main.py`.
3. Откройте терминал в папке с файлом и выполните:

   ```bash
   python main.py
